# Skill: Academic Writing in Russian (Академическое письмо на русском языке)

## Purpose

This skill provides comprehensive guidance for writing high-quality, original academic texts in Russian — coursework (курсовые работы), term papers, and research projects. It covers structure, style, citation standards (ГОСТ), formatting, and techniques for producing authentic scholarly prose.

## When to Use

- User asks to write or edit a coursework (курсовая работа), term paper, or academic text in Russian
- User needs help structuring chapters, paragraphs, introductions, or conclusions
- User wants to improve academic style or fix stylistic issues
- User needs proper ГОСТ-compliant bibliography formatting
- User asks to paraphrase or rewrite text in academic Russian

---

## 1. Coursework Structure (Структура курсовой работы)

A standard Russian university coursework follows this structure:

### Введение (Introduction) — 1.5–2 pages
Must contain:
- **Актуальность темы** (topic relevance) — why this topic matters now
- **Цель работы** (purpose) — one sentence: "Целью курсовой работы является теоретическое и практическое обоснование [topic]"
- **Задачи** (objectives) — 4–6 specific tasks derived from the purpose
- **Объект исследования** (object of study) — the broad area
- **Предмет исследования** (subject of study) — the specific aspect
- **Методы исследования** (methods) — analysis, comparison, synthesis, etc.
- **Информационная база** (information base) — types of sources used
- **Структура работы** — brief description of chapters

### Глава 1. Теоретическая (Theoretical Chapter) — 8–10 pages
- 1.1 Понятие и сущность [topic] (concept and essence)
- 1.2 Методические подходы / показатели оценки / критерии [topic]
- 1.3 Отечественный и зарубежный опыт / перспективы развития
- **Выводы по главе 1** (5–7 sentences summarizing key findings)

### Глава 2. Аналитическая (Analytical Chapter) — 8–10 pages
- 2.1 Организационно-экономическая характеристика [company]
- 2.2 Анализ [topic] с использованием инструментов (SWOT, PEST, BCG, etc.)
- 2.3 Факторы, влияющие на [topic] / проблемная зона
- **Выводы по главе 2**

### Глава 3. Проектная (Project/Recommendations Chapter) — 8–10 pages
- 3.1 Концепция / мероприятия по совершенствованию [topic]
- 3.2 Обоснование эффективности предложений (экономическая оценка)
- 3.3 Оценка рисков / прогноз результатов
- **Выводы по главе 3**

### Заключение (Conclusion) — 1.5–2 pages
- Summary of conclusions from each chapter (по пунктам, ~8 пунктов)
- General conclusion about the achievement of the stated purpose
- Practical significance and recommendations

### Список литературы (Bibliography) — 35–40 sources
### Приложения (Appendices) — supplementary tables, charts, raw data

## 2. Academic Writing Style Rules (Правила научного стиля)

### Core Principles
1. **Безличность** — avoid first person. Use: "в рамках данного исследования установлено", "автором предложено", "представляется целесообразным"
2. **Терминологическая точность** — define key terms on first use, use them consistently
3. **Логическая связность** — every paragraph must follow the pattern: тезис → аргумент → пример/данные → вывод
4. **Краткость** — one idea per sentence. Remove filler words and redundant qualifiers

### Sentence Construction
- Average sentence length: 15–25 words (mix short and long)
- Vary sentence openings — do NOT start 3+ sentences in a row with the same word or structure
- Use transitional phrases between paragraphs: "В связи с вышеизложенным...", "Следует отметить, что...", "Вместе с тем...", "Таким образом..."
- Avoid chains of genitive cases (цепочки родительных падежей): "анализ результатов оценки эффективности деятельности компании" → break into shorter phrases

### Vocabulary
- Use precise Russian academic vocabulary, not calques from English
- Avoid bureaucratic clichés: "на сегодняшний день" → "в настоящее время" or just state the fact
- Avoid emotional/evaluative language: "огромный", "потрясающий" → "значительный", "существенный"
- Do not overuse intensifiers: "очень", "крайне", "чрезвычайно" — use sparingly

### What to Avoid (Common Markers of AI-Generated Text)
These patterns are flagged by plagiarism detection systems as signs of machine-generated text:

1. **Redundant double qualifiers** — "непрерывный трудоёмкий процесс", "комплексный всесторонний анализ" — pick ONE adjective
2. **Excessive bulleted/numbered lists** — convert lists into flowing prose or tables with analysis columns (Definition | Description | Your Conclusion)
3. **Formulaic structures** — "не только... но и...", "как... так и..." repeated multiple times — vary the syntax
4. **Uniform paragraph length** — vary between 3–7 sentences per paragraph
5. **Generic filler phrases** — "В современном мире...", "Как известно...", "Не секрет, что..." — start with specific facts
6. **Enumerations without analysis** — never just list items; every enumeration needs YOUR commentary explaining why it matters
7. **Perfect symmetry** — real academic text is slightly asymmetric; not every section needs the same number of subsections

### Paragraph Structure Pattern
```
[Название/тезис] → [Описание/раскрытие] → [Данные/пример] → [Вывод + связь со следующим параграфом]
```

Each paragraph's conclusion should bridge to the next paragraph's topic. Example:
> "Таким образом, анализ финансовых показателей свидетельствует о стабильном росте выручки компании. Вместе с тем для более полной оценки необходимо рассмотреть факторы внешней среды, влияющие на данную динамику."

## 3. Tables, Figures, and Visual Elements

### Rules
- Every chapter and subsection should contain at least one table or figure
- After every table/figure: write 5–7 sentences analyzing it — "Исходя из данных, представленных в таблице X, можно сделать вывод..."
- Never leave a table or figure without commentary
- When AI-generated text lists steps/stages — convert them into:
  - A flowchart (автофигуры) with brief descriptions of each stage, OR
  - A table with columns: Этап | Содержание | Значение/Результат

### Formatting (ГОСТ 7.32-2017)
- Tables: "Таблица 1 — Название таблицы" (above the table, left-aligned)
- Figures: "Рисунок 1 — Название рисунка" (below the figure, centered)
- Number tables and figures sequentially within the entire work or within each chapter (1.1, 1.2, 2.1...)

## 4. Citation and Bibliography (ГОСТ Р 7.0.100-2018)

### In-Text Citations
Use square brackets: [1, с. 45] or [1; 2; 5]

### Bibliography Format Examples

**Book (one author):**
```
Иванов, А. Б. Стратегический менеджмент : учебное пособие / А. Б. Иванов. — 2-е изд., перераб. — Москва : Юрайт, 2023. — 356 с. — ISBN 978-5-XXXX-XXXX-X.
```

**Book (two authors):**
```
Петров, В. Г. Корпоративное управление : учебник / В. Г. Петров, С. Д. Сидорова. — Москва : ИНФРА-М, 2022. — 428 с. — ISBN 978-5-XXXX-XXXX-X.
```

**Journal article:**
```
Козлова, Е. Н. Цифровая трансформация бизнес-моделей / Е. Н. Козлова // Вестник РЭУ им. Г. В. Плеханова. — 2024. — № 3. — С. 45–58.
```

**Electronic resource:**
```
Росстат : официальный сайт. — URL: https://rosstat.gov.ru (дата обращения: 15.03.2025).
```

**Laws and regulations:**
```
О стратегическом планировании в Российской Федерации : Федер. закон от 28 июня 2014 г. № 172-ФЗ // Российская газета. — 2014. — 3 июля.
```

### Bibliography Composition (35–40 sources)
- ~30% books and monographs
- ~30% journal articles (last 5 years preferred)
- ~20% electronic/internet resources
- ~10% laws, standards, statistical data
- ~10% foreign sources (if applicable)
- Sort alphabetically by author surname; numbered sources start with Russian, then foreign

## 5. Formatting Standards (ГОСТ 7.32-2017)

| Parameter | Value |
|-----------|-------|
| Font | Times New Roman, 14 pt |
| Line spacing | 1.5 |
| Margins | Left 30 mm, Right 10–15 mm, Top/Bottom 20 mm |
| Paragraph indent | 1.25 cm |
| Alignment | Justified (по ширине) |
| Page numbers | Bottom center, starting from page 2 (title page = page 1 but unnumbered) |
| Chapter headings | UPPERCASE, bold, centered, no period at end |
| Subsection headings | Sentence case, bold, left-aligned with paragraph indent |
| Spacing before/after headings | 1 empty line before, 1 empty line after |

## 6. Paraphrasing Technique (Парафразирование)

When rewriting text from sources to make it original:

1. **Read and understand** the source paragraph fully
2. **Close the source** and write the idea in your own words
3. **Change the sentence structure**: active → passive, simple → complex, or vice versa
4. **Replace key terms with synonyms** where appropriate (but keep standard terminology)
5. **Add your analytical commentary** — this is what makes text original
6. **Cite the source** even after paraphrasing: [1, с. 34]

### Example
**Source:** "Стратегическое управление представляет собой процесс принятия и осуществления стратегических решений, центральным звеном которого является стратегический выбор."

**Paraphrased:** "Под стратегическим управлением в научной литературе принято понимать комплекс управленческих решений долгосрочного характера, ключевым элементом которого выступает обоснованный выбор направления развития организации [1, с. 34]. Данный подход позволяет компании адаптироваться к изменениям внешней среды и формировать устойчивые конкурентные преимущества."

## 7. Chapter-by-Chapter Writing Checklist

### Before Writing
- [ ] Determine the topic, purpose, and 4–6 objectives
- [ ] Find 35–40 sources (books, articles, websites, laws)
- [ ] Create a detailed outline (план) approved by the supervisor

### Chapter 1 (Theoretical)
- [ ] Define key concepts with references to 3+ authors
- [ ] Present at least 2 methodological approaches with comparison
- [ ] Include 1–2 tables summarizing theories or methods
- [ ] Write chapter conclusions (5–7 sentences)
- [ ] Ensure every paragraph has a source citation

### Chapter 2 (Analytical)
- [ ] Describe the company: legal form, structure, activities, key financials (3 years)
- [ ] Apply analytical tools: SWOT + at least one more (PEST, BCG, Porter's 5 Forces)
- [ ] Include 3–5 tables with real data and analysis after each
- [ ] Identify specific problems with evidence
- [ ] Write chapter conclusions linking problems to Chapter 3 recommendations

### Chapter 3 (Project)
- [ ] Propose 2–3 specific measures addressing problems from Chapter 2
- [ ] Calculate expected economic effect (before/after comparison table)
- [ ] Assess risks (risk matrix or classification)
- [ ] Write chapter conclusions

### Introduction and Conclusion
- [ ] Write Introduction AFTER all chapters are done (to accurately reflect content)
- [ ] Conclusion summarizes findings from each chapter in 8+ points
- [ ] Verify that stated objectives match actual content

### Final Check
- [ ] All tables and figures have analysis text (5–7 sentences each)
- [ ] No bulleted lists in the main text — convert to prose or tables
- [ ] Paragraph transitions are smooth (each ending connects to the next topic)
- [ ] No redundant double qualifiers
- [ ] Varied sentence structure (no repetitive patterns)
- [ ] All sources in bibliography are cited in text, and vice versa
- [ ] Formatting matches ГОСТ requirements
- [ ] Page count meets requirements (typically 30–40 pages for main text)

## 8. Useful Academic Phrases (Клише научного стиля)

### Introduction
- "Актуальность исследования обусловлена..."
- "Целью настоящей работы является..."
- "Для достижения поставленной цели необходимо решить следующие задачи:..."
- "Объектом исследования выступает..."
- "Предметом исследования являются..."
- "Теоретической основой исследования послужили труды..."
- "Методологическую базу составили..."

### Analysis and Argumentation
- "Анализ показал, что..."
- "Полученные данные свидетельствуют о..."
- "Следует подчеркнуть, что..."
- "Представляется целесообразным отметить..."
- "По мнению [автор], ... [1, с. X]"
- "В работах [автор] обосновывается положение о том, что..."
- "Сопоставление результатов позволяет утверждать..."

### Transitions Between Sections
- "В связи с вышеизложенным..."
- "Вместе с тем необходимо учитывать..."
- "Переходя к рассмотрению [topic]..."
- "Для более детального анализа обратимся к..."
- "Изложенные теоретические положения целесообразно рассмотреть на практическом примере..."

### Conclusions
- "Таким образом, проведённый анализ позволяет сделать следующие выводы:..."
- "На основании изложенного можно заключить..."
- "Результаты исследования подтверждают..."
- "Практическая значимость полученных результатов заключается в..."
