# Academic Writing in Russian (Академическое письмо на русском языке)

Write high-quality, original academic texts in Russian — coursework (курсовые работы), term papers, and research projects. Integrates academic structure, ГОСТ formatting, Russian typography, AI-pattern detection and removal, and natural Russian prose style.

## When to Use

- User asks to write or edit a coursework (курсовая работа), term paper, or academic text in Russian
- User needs help structuring chapters, paragraphs, introductions, or conclusions
- User wants to improve academic style, fix stylistic issues, or remove AI-generated patterns
- User needs proper ГОСТ-compliant bibliography formatting
- User asks to paraphrase, rewrite, or humanize text in academic Russian

## 1. Coursework Structure (Структура курсовой работы)

### Введение (Introduction) — 1.5–2 pages
Must contain:
- **Актуальность темы** — why this topic matters now
- **Цель работы** — one sentence: "Целью курсовой работы является теоретическое и практическое обоснование [topic]"
- **Задачи** — 4–6 specific tasks derived from the purpose
- **Объект исследования** — the broad area
- **Предмет исследования** — the specific aspect
- **Методы исследования** — analysis, comparison, synthesis, etc.
- **Информационная база** — types of sources used
- **Структура работы** — brief description of chapters

### Глава 1. Теоретическая — 8–10 pages
- 1.1 Понятие и сущность [topic]
- 1.2 Методические подходы / показатели оценки
- 1.3 Отечественный и зарубежный опыт
- **Выводы по главе 1** (5–7 sentences)

### Глава 2. Аналитическая — 8–10 pages
- 2.1 Организационно-экономическая характеристика [company]
- 2.2 Анализ [topic] (SWOT, PEST, BCG, etc.)
- 2.3 Факторы / проблемная зона
- **Выводы по главе 2**

### Глава 3. Проектная — 8–10 pages
- 3.1 Мероприятия по совершенствованию [topic]
- 3.2 Обоснование эффективности предложений
- 3.3 Оценка рисков / прогноз результатов
- **Выводы по главе 3**

### Заключение — 1.5–2 pages
Summary of conclusions from each chapter (~8 points), practical significance, recommendations.

### Список литературы — 35–40 sources
### Приложения — supplementary tables, charts, raw data

## 2. Russian Typography (Типографика)

Apply these rules to ALL Russian text output without exception.

| Rule | Wrong | Correct |
|---|---|---|
| Primary quotes: guillemets | "текст" | «текст» |
| Nested quotes: lapki | «"вложенные"» | «„вложенные"» |
| Em dash with spaces | слово - слово | слово — слово |
| En dash for ranges, no spaces | 10-15 дней | 10–15 дней |
| NBSP after single-letter prepositions | в начале | в\u00A0начале |
| Ellipsis: single character | ... | … |
| Digit groups with thin spaces | 1000000 | 1 000 000 |
| Decimal comma | 3.14 | 3,14 |
| Ordinal with hyphen | 1ый | 1-й |
| Numero sign | No. 5, #5 | № 5 |
| Abbreviations with NBSP | т.д. | т. д. |

### Typography Checklist
- [ ] Quotes: «» primary, „..." nested
- [ ] Dashes: — in text, – in ranges, - only in compounds; max 1–2 per paragraph
- [ ] NBSP after в, к, с, о, у, и, а
- [ ] Abbreviations: т. д., т. п. (with NBSP)
- [ ] No double spaces, no space before punctuation

## 3. Academic Writing Style (Правила научного стиля)

### Core Principles
1. **Безличность** — avoid first person. Use: "в рамках данного исследования установлено", "автором предложено"
2. **Терминологическая точность** — define key terms on first use, use them consistently (do NOT cycle synonyms)
3. **Логическая связность** — every paragraph: тезис → аргумент → пример/данные → вывод
4. **Краткость** — one idea per sentence. Remove filler words and redundant qualifiers
5. **Активный залог** — prefer active voice with named subjects over passive constructions

### Sentence Construction
- Average length: 15–25 words (mix short and long for natural rhythm)
- Vary sentence openings — do NOT start 3+ sentences the same way
- Avoid chains of genitive cases — break into shorter phrases

### Paragraph Structure
```
[Тезис] → [Описание/раскрытие] → [Данные/пример] → [Вывод + связь со следующим параграфом]
```

Each paragraph's conclusion should bridge to the next paragraph's topic.

## 4. AI-Pattern Detection and Removal (Humanizer)

These patterns are flagged as signs of machine-generated text. Remove them from all output.

### 4.1 Content Patterns

**Искусственная сверхзначимость:** Remove words like "выступает в роли", "оставил неизгладимый след", "символизирует", "вносит значимый вклад". Replace with concrete facts.

**Псевдоглубина через деепричастные обороты:** Avoid "отражая", "подчеркивая", "демонстрируя", "символизируя" at end of sentences. State the cause directly.

**Рекламный пафос:** Remove "восхитительный", "непревзойденный", "в самом сердце", "настоящий оазис". Use plain descriptions.

**Размытые ссылки:** Replace "эксперты считают", "исследования показывают" with specific citations: author, year, publication.

**Шаблон «Вызовы и Перспективы»:** Replace "светлое будущее" and "заглядывая вперед" with specific plans and numbers.

### 4.2 Language Patterns

**Избегание глагола-связки:** AI replaces simple "является"/"это" with bureaucratic constructions. Use simple forms.

**Правило Трёх:** AI groups things in threes for rhythm. Use the natural number of items instead.

**Синонимическая замена:** AI avoids repetition by cycling synonyms — this looks unnatural. Use one precise term consistently. Example: "Генеральный директор компании" (then just "директор"), not "руководитель... глава... топ-менеджер... лидер".

**Избыточные двойные определения:** Choose ONE adjective, not two. "трудоёмкий процесс", not "непрерывный трудоёмкий процесс".

### 4.3 Structural Patterns

**Бинарные противопоставления:** Never use "Это не просто X, это Y" or "Речь идет не только о X, но и о Y". State Y directly.

**Ложная субъектность:** Inanimate objects don't act. Name the real actor. "Было принято решение" → "Руководитель отдела решил..."

**Драматическая рубка фраз:** Avoid "[Noun]. Вот и все." and "А. И еще Б. И еще В." Write complete sentences.

See [references/structures.md](references/structures.md) for full pattern tables with examples.

### 4.4 Style Patterns

**Обилие длинных тире:** Max 1–2 em dashes per paragraph. Use commas or periods instead.

**Жирный шрифт и списки:** In academic text, bold is only for headings. No bulleted lists in main text — convert to prose or tables.

**Равномерная длина абзацев:** Vary between 3–7 sentences. Uniform length = AI marker.

## 5. Stop-Words and Phrases

### Remove completely
- "Важно отметить, что", "Стоит подчеркнуть", "Нельзя не упомянуть"
- "В современном мире...", "В быстро меняющемся мире..."
- "Как известно...", "Не секрет, что..."
- "Давайте рассмотрим", "В заключение хочется сказать"

### Replace bureaucratic language with simple verbs
| Avoid | Use |
|---|---|
| является | — (dash) or restructure |
| осуществлять | делать, проводить |
| в настоящее время | сейчас |
| данный | этот |
| на сегодняшний день | сегодня |
| в целях | чтобы |
| выступает в роли | это, работает как |

### Remove filler adverbs
"действительно", "просто", "буквально", "абсолютно", "глубоко", "поистине", "фундаментально", "кардинально", "безусловно"

### ChatGPT markers in Russian
"Полотно", "Мозаика", "Симфония", "Оазис", "Виртуозный" — replace with plain descriptions.
Overuse of abstract nouns: "Трансформация", "Инновация", "Интеграция" — describe the action with a verb instead.

See [references/phrases.md](references/phrases.md) for complete phrase lists with replacements.

## 6. Humanization Process

When given text to humanize or rewrite:

1. **Анализ** — find all patterns from sections 4 and 5
2. **Удаление** — remove filler introductions, bureaucratic language, filler adverbs
3. **Перестройка** — break artificial structure (rule of three, binary contrasts, lists)
4. **Конкретизация** — replace abstractions with specific facts, numbers, names
5. **Оживление** — vary sentence rhythm, add natural transitions between paragraphs
6. **Проверка** — read result aloud, ensure it sounds natural and academic

See [references/examples.md](references/examples.md) for full before/after transformation examples.

## 7. Tables, Figures, and Visual Elements

- Every chapter must contain at least one table or figure
- After every table/figure: write 5–7 sentences analyzing it
- Never leave a table or figure without commentary
- Convert AI-generated lists into flowcharts or tables with columns: Этап | Содержание | Результат

### Formatting (ГОСТ 7.32-2017)
- Tables: "Таблица 1 — Название таблицы" (above, left-aligned)
- Figures: "Рисунок 1 — Название рисунка" (below, centered)
- Number sequentially within the entire work or within each chapter (1.1, 1.2, 2.1...)

## 8. Citation and Bibliography

See [references/gost-bibliography.md](references/gost-bibliography.md) for ГОСТ Р 7.0.100-2018 format examples for books, articles, electronic resources, and laws.

In-text citations: [1, с. 45] or [1; 2; 5]

Bibliography: 35–40 sources (~30% books, ~30% articles, ~20% electronic, ~10% laws, ~10% foreign). Sort alphabetically; Russian first, then foreign.

## 9. Formatting Standards (ГОСТ 7.32-2017)

| Parameter | Value |
|---|---|
| Font | Times New Roman, 14 pt |
| Line spacing | 1.5 |
| Margins | Left 30 mm, Right 10–15 mm, Top/Bottom 20 mm |
| Paragraph indent | 1.25 cm |
| Alignment | Justified (по ширине) |
| Page numbers | Bottom center, starting from page 2 |
| Chapter headings | UPPERCASE, bold, centered, no period |
| Subsection headings | Sentence case, bold, left-aligned with indent |
| Spacing | 1 empty line before and after headings |

## 10. Paraphrasing Technique

1. Read and understand the source paragraph fully
2. Close the source and write the idea in your own words
3. Change the sentence structure: active↔passive, simple↔complex
4. Replace key terms with synonyms where appropriate (keep standard terminology)
5. Add your analytical commentary — this makes text original
6. Cite the source even after paraphrasing: [1, с. 34]

**Example:**
Source: "Стратегическое управление представляет собой процесс принятия и осуществления стратегических решений, центральным звеном которого является стратегический выбор."

Paraphrased: "Под стратегическим управлением в научной литературе принято понимать комплекс управленческих решений долгосрочного характера, ключевым элементом которого выступает обоснованный выбор направления развития организации [1, с. 34]. Данный подход позволяет компании адаптироваться к изменениям внешней среды и формировать устойчивые конкурентные преимущества."

## 11. Anti-Slop System Prompt

When generating Russian academic text, internally apply this constraint:

```
СТРОГО ЗАПРЕЩАЕТСЯ:
1. Вводные штампы: "важно отметить", "стоит подчеркнуть", "в современном мире".
2. Отглагольные существительные: "инновация", "интеграция", "оптимизация" —
   описывайте конкретное действие глаголом.
3. Метафоры-клише: "полотно", "мозаика", "симфония", "оазис", "виртуозный".
4. «Правило трех»: избегайте перечислений из трех однородных прилагательных.
5. Бинарные клише: "Это не просто X, это Y", "С одной стороны... с другой...".
6. Канцелярит: замените "выступает в роли", "является свидетельством" на активные глаголы.

Принципы:
- Активный залог. Субъект совершает действие.
- Вырезайте половину прилагательных и наречий.
- Конкретика вместо абстракций.
```

## 12. Chapter-by-Chapter Writing Checklist

### Before Writing
- [ ] Determine topic, purpose, and 4–6 objectives
- [ ] Find 35–40 sources
- [ ] Create detailed outline approved by supervisor

### Chapter 1 (Theoretical)
- [ ] Define key concepts with references to 3+ authors
- [ ] Present 2+ methodological approaches with comparison
- [ ] Include 1–2 tables summarizing theories
- [ ] Chapter conclusions (5–7 sentences)
- [ ] Every paragraph has a source citation

### Chapter 2 (Analytical)
- [ ] Company description: legal form, structure, key financials (3 years)
- [ ] Analytical tools: SWOT + at least one more
- [ ] 3–5 tables with real data and analysis after each
- [ ] Specific problems identified with evidence
- [ ] Conclusions linking problems to Chapter 3

### Chapter 3 (Project)
- [ ] 2–3 specific measures addressing Chapter 2 problems
- [ ] Expected economic effect (before/after table)
- [ ] Risk assessment
- [ ] Chapter conclusions

### Final Quality Check
- [ ] All tables/figures have analysis (5–7 sentences each)
- [ ] No bulleted lists in main text
- [ ] Smooth paragraph transitions
- [ ] No redundant double qualifiers
- [ ] Varied sentence structure and paragraph length
- [ ] No AI-markers from sections 4–5
- [ ] All sources cited in text and vice versa
- [ ] Typography from section 2 applied
- [ ] ГОСТ formatting from section 9 applied
- [ ] 30–40 pages of main text
